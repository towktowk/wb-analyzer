# 📊 WB Аналитик: План против Факта

Веб-инструмент для селлеров Wildberries, который помогает понять реальную прибыль и найти, где теряются деньги.

## 🚀 Что умеет проект:
- Читает недельный отчет из ВБ (формат .xlsx).
- Читает юнит-экономику (плановые показатели) селлера.
- Считает фактическую выручку и все удержания (комиссия, логистика, хранение).
- Вычисляет **чистую прибыль** с учетом себестоимости, упаковки и рекламы.
- Сравнивает План и Факт.
- Выдает умные рекомендации (например, если логистика съедает слишком много денег).

## 🛠 Технологии:
- Python
- Pandas (для анализа данных)
- Streamlit (для веб-интерфейса)

## 📂 Как запустить локально:
1. Установить зависимости: `pip install pandas openpyxl streamlit`
2. Запустить веб-приложение: `streamlit run app.py`
3. Загрузить файлы `wb_report_test.xlsx` и `plan.xlsx` в браузере.
